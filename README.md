# DroneAcharya

AI-enabled drone and counter-drone **training simulator** (prototype) for a desktop PC, built with Godot 4.7.2.

**Synthetic training only:**

- fictional environments, traffic, hazards and sensors;
- procedural (non-kinetic) responses;
- simplified, non-graphic hazard mechanics;
- no operational capability or real-world accuracy claim.

Runs offline. No cloud services and no internet access are needed to play.

## Download and Run

For evaluators: a ready-made Windows build. Nothing else needs to be installed (no Godot, Python or internet connection).

**Download:** `<GOOGLE_DRIVE_LINK>` (file `DroneAcharya-<version>-win64.zip`, about 37 MB)

1. Download the ZIP. In Google Drive, use **Download** and, if asked, **Download anyway** (Drive cannot virus-scan files of this size).
2. Right-click the ZIP → **Extract All…** → **Extract**. Do not run the program from inside the ZIP.
3. Open the extracted folder `DroneAcharya-<version>-win64` and double-click **DroneAcharya.exe**.
4. If Windows SmartScreen says "Windows protected your PC", click **More info** → **Run anyway**. The program is not code-signed.

**System requirements**

- Windows 10 or 11, 64-bit.
- A graphics card or integrated GPU with a current Vulkan driver (tested). If Vulkan is unavailable, the engine is designed to fall back to Direct3D 12 or OpenGL 3.3. These fallbacks are untested.
- About 120 MB of disk space.
- A keyboard and mouse. The window is 1600×900 by default; 1366×768 is supported.
- Tested on one PC only: Windows 11 Home (64-bit), Intel Core Ultra 5 125H, Intel Arc integrated graphics (Vulkan), 16 GB RAM. Other hardware has not been tested.

Settings, reports and logs are saved in `%APPDATA%\DroneAcharya\`. The `README.txt` in the ZIP has the controls, troubleshooting and known limitations.

Maintainers: build the ZIP with `.\deploy\build-release.ps1 -Target Windows` (see `deploy/WINDOWS_RELEASE.md`).

## Requirements (running from source)

The Godot engine is **not** in this repository (the binaries are git-ignored). Before the first run:

1. Download **Godot 4.7.2 stable, standard build, Windows 64-bit** (`Godot_v4.7.2-stable_win64.exe.zip`, *not* the .NET build) from the official Godot download archive (https://godotengine.org/download/archive/).
2. Extract both files, `Godot_v4.7.2-stable_win64.exe` and `Godot_v4.7.2-stable_win64_console.exe`, into this folder (next to this README). They stay untracked.
   If Godot is installed elsewhere, use its full path in place of `.\Godot_v4.7.2-stable_win64.exe` below.
3. A graphics driver with Vulkan support (the project uses the Forward+ renderer).

No import step, export templates, Python or internet connection is needed to play. Python 3 with `ml/requirements.txt` is only needed for the ML and schema tests.

## Quick start (Windows, PowerShell, from this folder)

```powershell
.\Godot_v4.7.2-stable_win64.exe --path simulator                                                 # play
.\Godot_v4.7.2-stable_win64_console.exe --headless --path simulator --script res://tests/run_tests.gd   # 170 tests
python -m unittest discover -s ml/tests ; python -m unittest discover -s schemas                  # 11 + 4 tests
```

Saved settings, reports and logs are in `%APPDATA%\DroneAcharya\`. For a live demonstration, see `docs/LIVE_DEMO_RUNBOOK.md`.

## Training modes

**Flight Training**

- **Choose:** a mission and a drone profile (Scout, Recon, Heavy utility) on the flight briefing.
- **Environments:** a training course, a procedural city and a procedural village. Each has a hostile-area variant with simulated projectiles and a hostile drone.
- **Objectives:** fly the numbered rings in order and land in the zone before the time limit, with battery and integrity limits.
- **Synthetic radar:** range-limited, with noise and dropouts. It shows friendly, unknown and hostile contacts and simulated projectiles, each with its own shape and letter.

**Threat Detection Training**

- **First visit:** a short interactive tutorial.
- **Exercise:** observe synthetic contacts from a fictional post, using eye or simulated sensor view, a radar of tracker output and a contacts list.
- **Decisions:** a mouse-first decision card. Wheel to choose, right-click to confirm; alarms need one more confirmation.
- **Decision support:** labelled by method (rule-based baseline and a trained ML classifier).

**Training History & Reports**

- Plain-language reports built only from recorded data: result, what went well, what to improve, important decisions, next practice.
- The full scoring details on request.
- Deterministic 3D replay of threat exercises, plus export and import.

**Settings**

- Master, effects and ambience volume; mute.
- Mouse sensitivity.
- Effects quality.
- Decision-model information.
- All saved locally.

**Sound** is generated by the program; there are no audio files. Every alarm sound has a visual sign.
