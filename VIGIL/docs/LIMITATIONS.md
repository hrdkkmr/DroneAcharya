## Device/origin-local history and data-loss boundaries

- IndexedDB v1 persists actual completed **and aborted** reports, anonymous profiles and valid draft/selection. Only transaction completion marks saved. Quota/denial failures keep the actual in-memory report and show retry/backup; unsaved reports do not enter means/trends.
- **Not a cloud service or automatic backup.** Browser profiles, origins/ports, preview hosts and private modes have separate storage; clearing/changing them can make history unavailable. Eviction, disk/OS/browser crashes and user site-data clearing can lose acknowledged data. No general durable-hardware guarantee. Download JSON manually, especially before reset/host changes.
- No active simulation persistence, refresh/crash recovery or invented interrupted result. The beforeunload warning is not storage and browser prompts can be suppressed. A valid Lab draft reloads but no briefing/run auto-starts.
- Normal backup contains valid actual records, including unsaved memory copies; invalid stored entries remain quarantined/untouched. Raw diagnostic preserves originals but is deliberately not importable. Missing/schema-invalid metadata blocks normal load rather than overwriting unknown data. No automatic salvage/migration; export what is available before explicit reset.
- Reset clears local reports/profiles/preferences/quarantine/unsaved state and creates fresh zero-history demo definitions. It is destructive and confirmed, not undoable. Console discard/reset leaves saved history intact. Epoch checks prevent stale-tab resurrection, not multi-device synchronization.
- Initial3 anonymous definitions have no performance history. Added profile dates and session dates are actual; fixed demo-definition dates are not attempt data. Do not enter real personnel/training/PII; free text has no automatic PII detection or access control.

## Portable records / reporting trust and bounds

- Portable `vigil-session-export` format 1 accepts schema 3/generator-2/sensor-2/rubric-1/replay-1 only. Strict bounded shape/version/dates/identity/log/references/definition/evaluator checks reject inconsistent data and same-ID changes; they do not silently repair or import legacy schema 1/2. Older phases remain in Git; no legacy durable store existed to migrate.
- **Consistency ≠ authenticity.** An unsigned client file can be manufactured consistently. No identity proof, examination security, digital signature or authenticated instructor role. Do not interpret imported teaching scores as verified authorship/real-world performance.
- File limit20 MiB/500 profiles/500 reports; per-report 2 MiB/5000 events/8 tracks. Whole-history backup can exceed limits after enough real attempts; export individual reports. No automatic retention/trimming. Prolonged large-dataset loading/validation/performance has not been benchmarked.
- CSV is formula-safe quoted summary, not import format. HTML is self-contained/escaped; browser print delegates PDF/printer to the user agent. Print portal/cleanup and actual headless Chromium PDF generation were tested, not every OS print dialog/printer or PDF visual/extracted-text correctness.
- Private export/import/reset/print/current/prior answer/replay controls have root guards while active, including paused/disconnected state. This is presentation/API hygiene, not a trusted service.

## Descriptive analytics and separate heuristic inference

Only acknowledged saved/completed/comparable records enter score/components/trend/comparison. Aborted/no-evidence/unsaved records remain reviewable with exclusions. Missing marks/reports stay missing, not artificially fast zero latency. Profile/group sample sizes and attempt-weighted unit means reflect actual local records; empty means are null/dashes, not fictional zeros.

Small samples, editable weights/objectives and changed exercise/conditions/difficulty/seeds make raw means/differences **not normalized improvement, mastery, rankings or operational readiness**. A single point is not a trend. SVG/data-table views remain descriptive.

The separate rules-1 policy derives five component-credit means from≤5 distinct seeds in the latest matching context and discloses n/range/source IDs. Sample labels are not statistical confidence. Difficulty uses the latest3 distinct matching consistent actual attempts and fixed public teaching thresholds, moving at most1 within1–5; sparse/mixed/repeated/noisy evidence holds. This is intentionally conservative, not a validated learning model. Changing objectives, weights, type, conditions or difficulty restarts matching-context evidence; repeated focus changes can therefore hold difficulty for a long time. Source dates are user/device-originated, not a trusted chronology; equal dates use ID order, not fabricated execution times.

Recommendations are derived from current saved history, not persisted historical policy decisions. A later AAR visit can show a different plan; its actual score never changes. Novelty covers known saved seeds of that profile only, not forgotten/unsaved/other-machine history or global uniqueness. Aborted/no-evidence saved seeds affect avoidance only. Review and Start remain explicit; manual repeated-seed practice is allowed. See ADAPTATION_SPEC.md.

## Recorded review / Worker boundaries

One deterministic rubric-1 evaluator, six components/P1–P3 and raw per-track audits; not validated readiness/learning effectiveness. Objectives/weights are editable; tree structure/evidence/timing thresholds are stored/explained/validated, not arbitrary instructor-editable. Replay folds actual prefixes, not generated tracks or undelivered evidence. Tested unavailable capability/injected transport error, not every OS/timeout/crash path. Leaving console/opening guide/confirmation pauses; backgrounding a running tab does not. ## Prebuilt archive / local host

The ZIP supplies source/lock/tests/docs and tested production assets plus a Node-built-ins-only HTTP host. Node must already be available; no runtime npm install is needed. `dist/index.html` is not a file:// application. Stable browser/profile/host/port is needed to revisit the same local history. The server binds0.0.0.0 for preview compatibility, is unauthenticated and should not be exposed publicly. No TLS/rate limiting/accounts/server database/cloud backup or deployment SLA is supplied.

SHA-256 inventory detects changed/missing bytes but is not a signed publisher identity. Source excludes Git internals, dependencies/caches, credentials and user-created history. Development/browser tests require optional npm/browser/system installation; the supplied app does not. Performance sizes/build times are observations, not low-end or large-dataset benchmarks.

Known same-epoch peer notices withhold planning until actual reload; they do not automatically merge every tab. If BroadcastChannel is unavailable, peer changes cannot be discovered automatically.
