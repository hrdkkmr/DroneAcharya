## Contracts agreed before implementation

Consume only validated actual terminal records plus acknowledged saved IDs and selected anonymous profile. Ignore aborted/no-evidence/unsaved/other-profile performance. Never seed result history or change evaluations.

Keep actual source session IDs/scores/sample sizes/spread. Fixed teaching thresholds/sample labels are not calibrated probabilities, learning effectiveness or readiness. Repeated exact definitions do not inflate the independent sample count.
- Matching context includes exercise type, environment/lighting/weather, sensor settings, pattern/count/duration, difficulty, objectives and weights; ignores seed and cosmetic preset ID. Mixed contexts remain descriptive, not normalized ability. Deterministic weakest-mean target; tie breaks by shared SKILLS order. No eligible history selects a labelled Level1 foundation, no invented weakness.

Increase requires every score≥80, every skill≥75 and no explicit penalties; decrease requires every score<55 and weakest estimated component<60. Sparse/inconsistent/mixed/repeated/boundary evidence holds. A single noisy result can never increase difficulty.

Generate a deterministic fresh uint32 seed (+7919 stride) unused by any saved attempt of that profile (including abort/no-evidence for repeat avoidance only). Do not repeat a known exact exercise.
